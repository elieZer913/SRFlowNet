# SRFlowNet

Official implementation of:

**SRFlow: A Dataset and Regularization Model for High-Resolution Facial Optical Flow via Splatting Rasterization**

---

## Overview

SRFlowNet is a high-resolution facial optical flow model designed for modeling subtle facial motion in image space.

It is trained on the **SRFlow dataset** and introduces regularization strategies for improving motion consistency.

SRFlowNet focuses on **2D optical flow estimation**, independent of 3D scene flow modeling.

---

## Relationship to SRFlow3DNet

SRFlowNet serves as the foundation for our subsequent work on scene flow.

* **[SRFlowNet](https://github.com/elieZer913/SRFlow3DNet)** models 2D optical flow
* **SRFlow3DNet** extends it to 3D scene flow

This repository contains the standalone optical flow model and training framework.

---

## Dataset

We use the **SRFlow dataset**, generated by our pipeline:

👉 [SRFlowCore Repository Link](https://github.com/elieZer913/SRFlowCore)

Only the optical flow component is required.

---

## Key Contributions

* High-resolution facial optical flow modeling based on the SRFlow dataset
* Geometry-aware regularization for consistent motion estimation
* Strong performance on subtle facial motion and downstream tasks
